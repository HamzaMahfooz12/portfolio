---

## 🌟 Key Features

- **🌓 Dark / Light Mode Switcher:** Supports instant theme toggling with `localStorage` persistence and automatic system preference detection.
- **📱 Fully Responsive Layout:** Mobile-friendly design with a custom hamburger menu, fluid grid, and glassmorphic UI components.
- **🔍 Filterable Projects Showcase:** Filter projects dynamically by category (*All*, *Mobile*, *Frontend*, *Fullstack*, *AI / Computer Vision*).
- **🪟 Interactive Project Details Modal:** View expanded descriptions, tech stacks, GitHub repositories, and download links without leaving the page.
- **⚡ High Performance:** Built on Vite for near-instant hot module reloading and lightweight production asset bundling.
- **📬 Interactive Contact Form:** Clean client-side form interface with validation and submission feedback.

## 💻 Local Development Setup

Clone the repository and install the dependencies:

```bash
# Clone the repository
git clone https://github.com/HamzaMahfooz12/portfolio.git

# Navigate into the project directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Build for production:

```bash
# Create optimized production build
npm run build

# Preview production build locally
npm run preview
```
